# Портфолио: Python-боты, парсеры и автоматизация

Привет, я Ivan. Делаю на Python то, что чаще всего заказывают на фриланс-биржах: **парсеры, Telegram-боты и интеграции/автоматизацию**. Каждый проект ниже — рабочий, с настройкой через `.env`, README и автотестами.

Запуск каждого проекта — в его README (около 5 минут). Тесты: `pip install -r requirements.txt && pytest` внутри папки проекта.

## Анализ рынка (Kwork, биржа проектов, октябрь 2026)
Рубрика «Скрипты, боты и mini apps»: 24 открытых проекта; по всей бирже за месяц — 5 722 проекта на ~59,7 млн ₽, 2 980 заказов.

- **Чаще всего просят:** парсеры (сайты, цены в Google-таблицу, каталоги), Telegram/MAX-боты (в т.ч. с ИИ), интеграции с API и CRM (Wildberries, amoCRM, Битрикс24), ИИ-агенты, Mini Apps.
- **Бюджеты:** простые задачи 500–3 000 ₽, типовые 3 000–15 000 ₽ (парсер или бот), сложные 30 000+ ₽.
- **Конкуренция:** на «ходовые» парсеры и боты 50–119 откликов; на узкие интеграции и автоматизацию (AdsPower, A-Parser, ZennoPoster, amoCRM) обычно 3–20. Много заказов с бюджетом «до 500 ₽» — это не целевые.
- **Вывод:** проекты закрывают самые частые запросы (парсер → таблица, бот с заявками, форма сайта → мессенджер), а упор в описаниях на надёжность (ретраи, валидация, тесты) помогает выделиться среди десятков откликов.
