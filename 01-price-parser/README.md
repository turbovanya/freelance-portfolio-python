# Парсер цен → Excel / CSV

Собирает товары и цены из каталога, выгружает в таблицу и следит за изменением цен между запусками.

Для демо используется [books.toscrape.com](https://books.toscrape.com/) — учебный сайт, который специально сделан для парсинга. Чтобы перенастроить парсер на другой сайт, меняются CSS-селекторы в `parser/scraper.py` (функция `parse_catalog_page`).

## Что умеет

- проходит по страницам каталога (сколько страниц, задаётся параметром)
- повторяет запрос при обрыве связи и ошибках 5xx, на 404 сразу останавливается
- фильтрует по цене, рейтингу и наличию
- сохраняет в **XLSX** (жирная шапка, автофильтр, закреплённая первая строка) и в **CSV** (`;` и UTF-8 с BOM, чтобы русский Excel открывал двойным кликом)
- хранит историю цен в SQLite; если что-то подорожало или подешевело, в XLSX появляется лист «Изменения цен»

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env
python main.py --max-pages 3 --min-rating 3
```

Все параметры: `python main.py --help`

| Параметр | Что делает |
|---|---|
| `--max-pages N` | сколько страниц обойти, `0` — все |
| `--min-price`, `--max-price` | диапазон цен |
| `--min-rating 1..5` | минимальный рейтинг |
| `--in-stock` | только товары в наличии |
| `--format csv\|xlsx\|both` | формат выгрузки (по умолчанию оба) |

Пример вывода:

```
2026-10-23 21:14:02 INFO Страница 1: 20 товаров (всего 20)
2026-10-23 21:14:03 INFO Страница 2: 20 товаров (всего 40)
2026-10-23 21:14:03 INFO Страница 3: 20 товаров (всего 60)
CSV : output/products.csv
XLSX: output/products.xlsx
Товаров: 37, изменений цен с прошлого запуска: 0
```

Готовый результат лежит в [`examples/`](examples) — [products.xlsx](examples/products.xlsx) и [products.csv](examples/products.csv).

## Структура

```
main.py              запуск из командной строки
parser/scraper.py    загрузка страниц и разбор HTML
parser/storage.py    история цен в SQLite
parser/export.py     выгрузка в CSV и XLSX
parser/config.py     настройки из .env
tests/               pytest
```

## Тесты

```bash
pytest
```

Проверяются разбор HTML (включая «битые» карточки), повторы запросов, фильтры, поиск изменений цен и обе выгрузки. Сеть не нужна.
