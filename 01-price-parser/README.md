# 01 · Парсер цен с экспортом в Excel/CSV и отслеживанием изменений

**Задача клиента:** «собирать цены/товары с сайта в таблицу и видеть, что подорожало или подешевело». Самый частый тип заказов в рубрике «Парсеры» на Kwork.

Демо работает на учебном сайте [books.toscrape.com](https://books.toscrape.com/) (парсинг разрешён). Под сайт заказчика меняются только CSS-селекторы в `parser/scraper.py`.

## Возможности
- Обход пагинации, повторы при сетевых ошибках, пауза между запросами
- Фильтры: цена от/до, рейтинг, только в наличии
- Экспорт в **XLSX** (заголовки, фильтр, закреплённая шапка) и **CSV** (открывается в русском Excel без «кракозябр»)
- История цен в SQLite: при повторном запуске лист «Изменения цен» показывает было/стало/разницу
- Настройки через `.env`, запуск из командной строки

## Запуск за 5 минут
```bash
pip install -r requirements.txt
cp .env.example .env        # при желании поправьте настройки
python main.py --max-pages 3 --min-rating 3
pytest
```

## Пример вывода
```
Страница 1: 20 товаров (всего 20)
Страница 2: 20 товаров (всего 40)
Страница 3: 20 товаров (всего 60)
CSV : output/products.csv
XLSX: output/products.xlsx
Товаров: 37, изменений цен с прошлого запуска: 0
```
Реальный результат прогона лежит в репозитории: [`examples/products.xlsx`](examples/products.xlsx), [`examples/products.csv`](examples/products.csv).

## Стек
Python, requests, BeautifulSoup4 + lxml, openpyxl, SQLite, pytest (6 тестов: разбор HTML, фильтры, история цен, экспорт).
