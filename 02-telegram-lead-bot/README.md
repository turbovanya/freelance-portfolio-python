# Telegram-бот: FAQ и приём заявок

Бот для небольшого бизнеса: отвечает на типовые вопросы и собирает заявки, которые сразу приходят владельцу в личку.

## Что умеет

- меню из двух кнопок: «Оставить заявку» и «Частые вопросы»
- отвечает на вопросы, написанные своими словами: ищет по ключевым словам из `faq.json`, этот файл можно править без программиста
- заявка в три шага: имя → телефон (можно одной кнопкой «Отправить мой номер») → комментарий
- проверяет имя и телефон, любой формат номера приводит к `+7XXXXXXXXXX`
- выйти из формы можно в любой момент: кнопка «Отмена» или `/cancel`
- заявка сначала сохраняется в базу и только потом отправляется админам, поэтому не пропадёт, если отправка не прошла
- для админов: `/stats` (сколько заявок всего и за сутки) и `/export` (CSV для Excel)

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env
python main.py
```

В `.env` нужно вписать:

| Переменная | Где взять |
|---|---|
| `BOT_TOKEN` | у [@BotFather](https://t.me/BotFather) |
| `ADMIN_IDS` | свой ID у [@userinfobot](https://t.me/userinfobot), несколько ID через запятую |
| `BUSINESS_NAME` | название, которое бот покажет в приветствии |

Важно: админ должен один раз нажать `/start` у бота, иначе Telegram не даст боту ему написать.

## Как это выглядит

```
Клиент:  /start
Бот:     Здравствуйте! Это бот «Студия «Пример»». Выберите действие:

Клиент:  а сколько стоит?
Бот:     Стоимость зависит от объёма. Оставьте заявку — рассчитаем за 15 минут.

Клиент:  📝 Оставить заявку → Иван → 8 (912) 345-67-89 → Нужен парсер
Бот:     Спасибо! Заявка №1 принята, скоро свяжемся.

Админу:  🔔 Новая заявка №1
         Имя: Иван
         Телефон: +79123456789
         Комментарий: Нужен парсер
         Telegram: @client
```

## Структура

```
main.py             запуск
bot/handlers.py     команды, меню и форма заявки (FSM)
bot/validators.py   проверка имени, телефона, комментария
bot/faq.py          поиск ответа по ключевым словам
bot/db.py           заявки в SQLite, статистика, CSV
faq.json            вопросы и ответы
```

## Тесты

```bash
pytest
```

Кроме отдельных функций, тесты прогоняют целые диалоги через `Dispatcher.feed_update`, при этом запросы к Telegram API подменяются. Проверяется путь заявки от `/start` до сообщения админу, неправильный ввод, отмена, FAQ и то, что обычный пользователь не может вызвать `/stats`. Токен не нужен.
