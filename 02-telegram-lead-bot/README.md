# 02 · Telegram-бот для приёма заявок + FAQ

**Задача клиента:** «бот для бизнеса: отвечает на частые вопросы, собирает заявки и присылает их мне». Типичный заказ в рубрике «Чат-боты».

## Возможности
- Меню, ответы на вопросы по ключевым словам (`faq.json` — правится без кода)
- Форма заявки (aiogram FSM): имя → телефон (или кнопка «Отправить номер») → комментарий; валидация и нормализация номера в `+7XXXXXXXXXX`
- Кнопка «Отмена» на любом шаге
- Мгновенное уведомление админам; заявки сохраняются в SQLite, даже если уведомление не дошло
- Команды админа: `/stats` (счётчики), `/export` (CSV-файл, открывается в Excel)
- Токен и ID админов — только через `.env`

## Запуск за 5 минут
```bash
pip install -r requirements.txt
cp .env.example .env     # впишите BOT_TOKEN (@BotFather) и свой ADMIN_IDS (@userinfobot)
python main.py
pytest                   # токен для тестов не нужен
```

## Пример диалога
```
Клиент: /start        → Бот: Здравствуйте! Это бот «Студия «Пример»». Выберите действие
Клиент: сколько стоит? → Бот: Стоимость зависит от объёма. Оставьте заявку — рассчитаем за 15 минут.
Клиент: 📝 Оставить заявку → Иван → 8 (912) 345-67-89 → Нужен парсер
Админ получает: 🔔 Новая заявка №1 / Имя: Иван / Телефон: +79123456789 / Комментарий: Нужен парсер / Telegram: @client
```

## Тесты (20)
Валидаторы, SQLite, поиск по FAQ, конфиг, а также **полный диалог через `Dispatcher.feed_update`** с подменой вызовов Telegram API: заявка, ошибки ввода, отмена, FAQ, защита админ-команд. Всё без токена и сети.

> Честно: с живым Telegram бот в этой сборке не запускался (нет токена) — проверено автотестами диалога.

## Стек
Python 3, aiogram 3, SQLite, python-dotenv, pytest + pytest-asyncio.
